## 数据完整性

五份文件本身均完整：

```text
3403-3404 行
采样率约 226.9 Hz
最大间隔小于 10 ms
20 ms 以上缺口为 0
无加速度或陀螺仪饱和
```

因此 `capture_002` 不是文件损坏。剔除原因是身体朝向不一致：

```text
capture_001: 约 123°，东南方向
capture_002: 约 211°，西南方向
capture_003: 约 123°，东南方向
capture_004: 约 123°，东南方向
capture_005: 约 123°，东南方向
```

第 2 条不能与其他四条直接做轴向比较，因此从有效统计中剔除。

## 结论

- 桌面支撑的 `+Y/-Y` 结果最好，倾角约 5-6°，方向近似对称。
- 墙面支撑的偏差约 11-15°，说明拳头或手肘支撑时，腕带方向没有保持足够水平。
- 当前不需要重做桌面组；墙面组可以作为较差支点对照，不应用于精确轴向基准。
- 安装旋转矩阵仍沿用上次会话结果，本会话不提供新的轴映射。
